# OpenAI Game 후속 맵 재설계 메모

- 넓어진 거리와 빨라진 속도는 좋지만 현재 맵은 황량해서 구역 이름 이상의 재미가 부족하다.
- 작은 배경·전경 사물을 촘촘히 두고, 글 없이 사물의 방향·간격·움직임으로 다음 비행선과 바람을 안내해야 한다.
- 큰 네모 조합을 줄이고 곡선, 겹친 장난감, 비대칭 윤곽으로 실제 비행선을 만든다.
- 같은 높이로 가는 구성은 2단계까지면 충분하다. 3단계부터 상승과 하강을 넣고, 4단계 이후 장비는 이전에 보이지 않던 높이와 구조를 열어야 한다.
- 3단계 바람 구역은 힘의 방향과 진입선을 더 정교하게 재설계한다.
- 후반 성장 쾌감은 거리뿐 아니라 낮은 장비로는 보지 못했던 장소와 구조를 처음 보는 데서도 나와야 한다.
- 이 메모는 후속 맵 재설계 입력이며 현재 음향 비교 중 맵 구현을 시작하라는 승인이 아니다.
