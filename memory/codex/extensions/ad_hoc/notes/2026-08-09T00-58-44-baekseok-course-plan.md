# 백석대 2026-2 수강계획 보류 결정

- 우진님은 소프트웨어학전공 3학년 2학기 시간표를 월·수·목 등교, 화·금 공강 방향으로 구성 중이다.
- 확정 과목은 프런티어십(한정수 월1), 컴퓨터공학부 채플(월3), 소프트웨어공학(이승화 월4,5), 빅데이터(이시은 사이버), 다함께 파이썬(손은영 목5,6), 창의융합 Leading Class(박지연 수7,8)이다.
- 기독교세계관은 아직 확정하지 않는다. 여자친구분의 월요일 기독교탐사 시간이 정해진 뒤 두 사람 시간표를 다시 대조해 월요일 또는 수요일 공용 분반을 선택한다.
- 현재 성적 우선 후보는 서현덕 월2, 기존 등교일 유지 후보는 김은득 수4이지만, 김은득 분반은 강의평상 A 성적 위험이 더 크다.
