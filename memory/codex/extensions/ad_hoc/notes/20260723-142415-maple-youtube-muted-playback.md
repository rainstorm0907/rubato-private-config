# MapleStory YouTube research playback rule

- YouTube research should use existing transcripts or subtitles first.
- Open the video only when visual evidence from a specific timestamp is required.
- Any browser or headless Chrome used for video inspection must be muted before playback, for example with `--mute-audio` or the player mute control.
- Prefer an isolated browser profile and do not use Woojin's real Chrome profile for this workflow.
