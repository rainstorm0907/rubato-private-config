- For anything curious or ambiguous, look in the documents and the actual evidence first, and if more than one interpretation or decision remains, always ask Woojin.
- Prefer Korean words a user (gamer) can understand easily. When the same sound or the same spelling splits in meaning, make the context clear or switch to another expression.
- If Woojin says he does not know the current state, do not start from stage names; explain from the start the screen and actions the gamer will actually see.
- docs/59 is the single top-priority canonical source for early equipment unlocks. The implementation approach is fluid, so do not freeze it in memory; reread the repository canonical source.
