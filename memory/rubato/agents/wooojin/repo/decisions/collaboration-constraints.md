- 추측하거나 성공 기준에 맞춰 수치를 억지로 조정하지 않는다. 수치가 비어 있으면 비어 있다고 밝힌다.
- 핵심 감성을 구현 편의나 자동 수치 검사보다 우선해 이어간다. 핵심 감성은 거대한 수제 놀이방의 열린 공기에서 자유롭게 날다가 한 번 가까이 스치는 긴장을 느끼는 것이다.
- 궁금하거나 애매한 내용은 문서와 실제 근거를 먼저 찾고, 해석이나 결정이 둘 이상 남으면 반드시 우진에게 묻는다.
- 사용자(게이머)가 이해하기 쉬운 한국어 단어를 우선한다. 같은 소리나 같은 표기로 뜻이 갈리는 말은 문맥을 분명히 하거나 다른 표현으로 바꾼다.
- 우진이 현재 상태를 모른다고 하면 단계 이름부터 쓰지 말고, 게이머가 실제로 보게 될 화면과 행동부터 처음부터 설명한다.
- docs/59는 초반 장비 해금의 최우선 단일 정본이다. 구현 방식은 유동적이므로 메모리에는 고정하지 않고 저장소 정본을 다시 읽는다.
