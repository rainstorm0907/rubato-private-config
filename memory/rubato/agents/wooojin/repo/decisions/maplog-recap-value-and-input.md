## Conclusion

- What was fun is leaving traces on a nationwide map and going back and forth, with the user's own photos at stops. Choosing the material is not the fun. Viewing has to be possible from the automatic result. Do not make selection mandatory labor, and do not read that as a ban on ever choosing.
- Current staging, entry, length, camera, and photo selection are `/Users/wooojin/App/maplog/record/PRODUCT.md`. The 9/11 list of possible improvements is not an open adoption queue.
- Playback photo selection does not use an LLM. A hesitation about connecting one is not an open question, and liking a hand-picked board is not evidence that an LLM is required.
- A longer period must not become a proportional pile of stops. “3년” and “500번” are examples, not a formula and not test values.

## Rationale

- Chose keeping the rediscovery of a large map, including when the location explanation is a bit unfriendly, as long as the region can still be gauged.
- Rejected: promoting the adjustable values from that trial to an optimum or a default. “세부적인 값들은 절대 지금 완벽하진 않아”.
- Rejected: reading unhesitating progress as shortening every move. “사진 없이 먼거리 갈때는 이동시간 좀 더 주고 카메라 보기만 하는것도 재미”.
- Rejected: turning a missing place or a thin trip into a stop-control feature. “직관적으로 '멈추는 기능 만들기'로 해결하면 절대 안될 문제”. The playback pause control is not that solution.
- Rejected: treating “maplog에 recap용 LLM을 연결하는건 좀 부담일 거같기도 해” as still open. PRODUCT selects photos on device, without an LLM.
