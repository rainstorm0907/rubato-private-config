- Keyboard: MCHOSE Ace68-I wired keyboard.
- On 2026-09-01, at the user's request, removed Karabiner's `left_option → keyboard_fn` mapping so the Ace68-I's left Alt acts as the macOS left Option.
- USB hub: 베이직기어 VH710 USB 3.2 USB-C 7-port vertical 10Gbps hub. `PC IN` is a single-host data connection and `5V IN` is auxiliary power only, so the hub alone cannot connect to a Mac and a Windows machine at the same time.
- 2026-09-01 studio-apartment network: the Windows PC receives a KT public IPv4 directly from the passthrough port `LAN(PC)` of an `olleh tv` set-top box, and the Mac connects to the building's shared Wi‑Fi `404` on the private network `192.168.0.0/24`. The two devices are not on the same LAN even though they are in the same room.
- In this setup, Tailscale-direct Sunshine/Moonlight streaming had a round-trip latency that varied across a measured `20.7–143.6ms` (10-run average `56.4ms`). Even after removing encoder errors with H.264-only and a 10Mbps cap, severe control latency remained.
- On 2026-09-01, Windows→Mac remote control was smooth in real use with RustDesk's Tailscale direct-IP connection. The Mac had the RustDesk system service and a fixed password (stored in Keychain) set. `RustDesk --password` prints a failure message yet returns exit code `0` without administrator rights, so it must not be judged a success. On 2026-09-02 a `sudo` run confirmed `Done!` and exit code `0`, and matched the real host password to the Keychain item. The Windows client must use `Legacy` keyboard mode with Ctrl/Command swap off to avoid modifier-key sticking, and the picture baseline is Balanced, 30fps, Adaptive bitrate, and Auto codec. Windows RustDesk remembers the true fullscreen state per target device.
- On 2026-09-02, in Mac→Windows RustDesk, `Legacy` handled ordinary characters and chat, but MapleStory skill keys did not register. The immediately previous `Map` did handle game controls, so `/Users/wooojin/Library/Preferences/com.carriez.RustDesk/peers/424637723.toml` was restored to `keyboard_mode = 'map'`. The earlier symptom of only the mouse working and the keyboard briefly dropping was a temporary problem of capture being released, and the verdict that `Map` itself was the cause was discarded.
- On 2026-09-02, in Windows→Mac RustDesk, both Windows 1.4.9 and 1.4.5 were unstable at passing the Korean/English key, and Karabiner could not see RustDesk's synthetic keys. Installed Hammerspoon 1.1.1 and, in `/Users/wooojin/.hammerspoon/init.lua`, configured left Ctrl + left Shift + Caps Lock as a direct toggle of `ABC ↔ 2-Set Korean`. Verified bidirectional switching `Korean → ABC → Korean` with Hammerspoon accessibility permission `true` and two synthetic-key presses. On Windows→Mac the Windows key is captured by the local OS, so turn on RustDesk's `Swap Ctrl/Command` and use the physical Ctrl as the Mac Command. The Korean/English toggle receives both the left Control (59) and left Command (55) paths so it works both before and after this swap, and each path was verified separately.
