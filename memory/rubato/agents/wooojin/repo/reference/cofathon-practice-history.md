## 모의대회 3일차 동기

상태: 사용자 확정. 2026-09-02, COFATHON 회고 글을 정정하는 맥락.

우진: "내가 대회 연습할때 1,2 일차때는 그냥 문제 해결하면서 하고서 쉬려고 했는데 생각해보니 openai 공동개최기도 하고 요즘 트렌드도 ai니까 실제 구현 문제 내부에 LLM 도입하는거까지 해서 한번 3일차 문제 풀어본거였어."

따라서 1·2일차에서 판단 주도권을 단계적으로 회수한 끝에 3일차 LLM 범위를 제한했다는 서사로 바꾸지 않는다. 정확한 흐름은 1·2일차에는 일반적인 문제 해결 연습을 했고 끝내려다가, OpenAI의 행사 참여와 AI 흐름을 생각해 실제 제품 안에 LLM을 도입하는 문제까지 3일차에 한 번 더 풀어본 것이다. 운영진 메일은 OpenAI를 공동개최가 아니라 스폰서로 명시하므로 공개 글에서는 `OpenAI가 참여한 대회`라고 쓴다.

## 원티드 이미지

상태: 사용자 확정. 같은 맥락.
