## Conclusion

- Do not judge a flow finished because one map scene looks done. At each step, what the user sees, the main action, what they can choose, and what is automatic have to be decided together. A finished-looking partial screen does not close a gap in the path.
- The current path is not install through saving a named journey. 1.0 is a map gallery plus a period Recap. A photo pin is a gallery, not a journey seed. Saved Journey, including a candidate range, confirm and edit, and saving a name, is outside 1.0. Canon: `/Users/wooojin/App/maplog/record/PRODUCT.md` and [[reference/projects/maplog-seed-first-decision.md]].

## Rationale

- Chose looking at the whole path after a pin-selection scene was treated as if the journey work were done.
- Rejected: designing, as current work, the steps of entering a journey, a candidate range, scene selection, confirm and edit, and saving a name. That entry was replaced. Recap starts from a period on its own tab.

## Symptom

“근데 이제 그뿐이 아니라 우리 뭐 하자고 했어? 다시 역브리프 해봐 나한테. 아까 우리 뭐 하자고 했고, 다시 처음부터 그냥 사용자 입장에서 설치부터 여정 생성까지 어떤 순서이고, 단계마다 어떤 선택이 있는지”
