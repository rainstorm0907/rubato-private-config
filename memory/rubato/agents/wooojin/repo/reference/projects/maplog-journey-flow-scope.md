## Look at the whole flow first

- Status: user confirmed · 2026-08-31.
- Do not judge the journey UX finished just because the scene of selecting a photo pin on the map is complete. Design, as one user flow, the value explanation after install, photo access and classification, the first map, entering a journey, the candidate range, scene selection, confirm and edit, and saving a name.
- At each step, decide together what the user sees, the main action they take, what they can choose, and what is handled automatically and not asked. Visual completeness of a partial screen must not hide a gap in the whole flow.
- Woojin's correction original: “근데 이제 그뿐이 아니라 우리 뭐 하자고 했어? 다시 역브리프 해봐 나한테. 아까 우리 뭐 하자고 했고, 다시 처음부터 그냥 사용자 입장에서 설치부터 여정 생성까지 어떤 순서이고, 단계마다 어떤 선택이 있는지”
