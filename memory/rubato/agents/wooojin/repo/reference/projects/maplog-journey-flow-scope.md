## 전체 흐름을 먼저 본다

- 상태: 사용자 확정 · 2026-08-31.
- 지도에서 사진핀을 선택하는 장면만 완성했다고 여정 UX가 끝난 것으로 판단하지 않는다. 설치 후 가치 설명, 사진 접근과 분류, 첫 지도, 여정 진입, 후보 범위, 장면 선택, 확인·편집, 이름 저장까지 한 사용자 흐름으로 설계한다.
- 각 단계에서 사용자가 보는 것, 하는 주 행동, 선택할 수 있는 것, 자동으로 처리되어 묻지 않을 것을 함께 정한다. 부분 화면의 시각 완성도가 전체 흐름의 누락을 가리면 안 된다.
- 우진의 교정 원문: “근데 이제 그뿐이 아니라 우리 뭐 하자고 했어? 다시 역브리프 해봐 나한테. 아까 우리 뭐 하자고 했고, 다시 처음부터 그냥 사용자 입장에서 설치부터 여정 생성까지 어떤 순서이고, 단계마다 어떤 선택이 있는지”
