2026-07-05 시작한 피부(피지·모공) 분석 프로젝트.

- 피부: 지성~복합성 티존, 코·볼 안쪽 모공+피지 필라멘트(코 오른쪽 틈새가 특히 고민, 이틀마다 차오름), 염증성 여드름 거의 없음, 코 주변 마찰성 붉은기 약간.
- 현 루틴: 아침저녁 순한 비누 세안(하루 1회 세안이면 시카레티놀만) / 토너 아누아 맑은 계열 / 낮 CNP 프로폴리스 앰플, 밤 이니스프리 레티놀 시카 앰플(3개월+, 거의 매일, 무자극) / 코스알엑스 세라마이드 크림 / 클렌징 오일 가끔.
- 확인된 공백: 선크림 주 1~2회 이하 (레티놀 사용자인데 차단 부족).
- 예산: 올리브영 2~3만원대 1~2개, 최대 5만원. 홈케어만, 시술 제외.
- 방향: BHA 2% 도입(레티놀과 교차 설계), 코팩·마찰 2차세안 같은 저근거 방법 배제. 바이럴/커뮤니티 정보는 걸러내고 문헌·공식 소스 기준으로만 추천하는 게 원칙.
- 사진 원본: ~/Downloads/IMG_1235~1241 (제품+저녁 얼굴), IMG_1243~1244 (기상 직후 세안 전 — 밤새 피지 많음, 지성 확정). 4주 뒤 비교는 같은 조건(기상 직후·자연광)으로.
- 확정 조정: 코스알엑스 크림 티존 존 분리(얇게), 코 틈새 2차 마찰 세안 중단, BHA는 콧방울 틈새 2주차부터(붉은기 때문), 선크림은 이즈앤트리 선세럼 보유 — 빈도만 매일로 승격.
- 2026-07-05 방향 전환(중요): 우진님 본인 진술로 홍조 재평가. 양볼~코 이어지는 붉은기, 몇 년째 지속, 열·운동·매운거·술에 확 달아오름 + 평소에도 은은한 배경 홍조. 좁쌀·농포 없음, 눈썹·코옆 각질 없음 → 홍조형(혈관형) 경향(초기 rosacea 스펙트럼 의심, 진단 아님·피부과 확인 필요). 지루성/염증형 아님.
- 재정립된 우선순위: 1순위=홍조 관리(트리거 회피=뜨거운물세안·사우나·매운거·술 회피 / 자극 최소 / 세라마이드+나이아신아마이드 장벽 / 선크림 매일 / 아젤라산). BHA는 필수템에서 강등 → 정 필요하면 미니 30ml 코에만 주1회 제한. 각질제거 세게 가면 홍조 악화 리스크.
- 선크림 양: IMG_1245는 검지 두 마디(손끝~2관절)뿐 = 투핑거룰의 약 1/3~1/2. 정량은 검지 full+중지 full 두 줄(펌핑식이면 2펌핑+). 홍조 때문에 매일·정량이 방어 핵심.
- 처방 옵션 안내함: 홍조형은 홈케어로 유지가 한계, 실제 개선은 피부과 바르는 처방(아젤라산 처방농도·메트로니다졸·브리모니딘)이 도구 — 시술 아님, 우진님 "시술 제외" 범주와 다름.
- 사진 원본 IMG_1237~1241 HEIC는 Downloads에서 사라짐(재확인 불가). 이후 홍조 판단은 본인 진술 기준(사진보다 신뢰).
