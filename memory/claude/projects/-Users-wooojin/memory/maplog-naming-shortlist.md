**Maplog는 메이플스토리와 전혀 무관** — 한국 10~20대 대상 장소 기록·모임 앱(지도 map + log). [[maple-gear-session]]과 이름만 비슷할 뿐 별개 프로젝트이니 혼동 금지(2026-08-10 혼동 사고 후 명시).

2026-07-14 네이밍 세션 결과. Maplog는 이름으로 약함(iOS "Map Log" 동일 발음 선점, ~log 포화, 설명형이라 정서 운반 못함).

우진님이 직접 좋다고 반응한 후보(순서대로): 발자꾹, 뭉치, 꾸러미, 총총, 모둠 — 그러나 **타깃 반응 "다 구리다, 명료했으면"** 으로 애칭 트랙 기각(2026-07-14). 명료 트랙(놀지도 등)은 "직관적인데 구리다"로 기각. **확정 아님 — 탐색 계속 중** (우진님: "최종 확정 멀었다, 종합적으로"). 기준 = 명료+시크(iPhone 기본앱 감성). 유력 후보(선점 없음 확인): **약도(초대장 뒷면 지도, 현재 최유력), 별표("별표 쳐놨어"), 좌표(GPS 유틸 검색 오염), 점점, 골목, 번지, 거기, 흔적**. 맵시는 맵시내비게이션과 반충돌. 영어 일반 단어(Placemark·Waypoint·Been)는 전부 선점 — 영어 트랙은 조어만 가능. 미탐색 트랙: 숫자 결합(인생네컷 문법), 시간 어휘, 의성어 재발견. 다음 실험 제안: 리캡 카드 목업에 이름별 워터마크 박아 비교.

전부 웹 검색 기준 앱 선점 없음 확인. 탈락(선점): 핀콕(여행사), 발도장(구석구석), 콕콕(앱테크), 차곡(언어학습), 뭉클(감사일기), 새록(탐조), 몽땅(부동산), 보따리(체크리스트), 주섬(링크), 모야(모야모), 갈피(인디 독후감 앱).

**Why:** 다음 단계는 타깃 5~10명 이름 테스트(연상→적합도 투표→검색 표기 테스트), 최종 1개 확정 후 KIPRIS 상표 조회 + 앱스토어 앱 내 직접 검색으로 마감.

**How to apply:** maplog 이름 얘기가 다시 나오면 이 쇼트리스트에서 이어가고, 새 후보 추가 전에 수확 체감(마지막 판 3판/3개)을 상기. 관련: [[hama-deploy-topology]] 아님, maplog는 `~/app/maplog`.
