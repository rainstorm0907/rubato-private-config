우진님 본인 명의로 쓰는 글(자소서, 지원서, 자기소개, 프로젝트 소개 등)의 표준 말투. 기준 샘플 = 2026-07-09 Cofathon Q1 최종 제출본([[cofathon-application]]).

문체 규칙:
- 담백한 평서문, "~습니다/~입니다"체. 과장·미사여구·감탄 없이 사실과 수치 중심.
- "A가 아니라 B다" 식 날선 대조나 격언조("~가 제 방식입니다"처럼 툭 던지는 단정)는 지양 → 부드럽게 풀어 서술("만드는 데서 멈추지 않고 그 결과가 맞는지 확인하는 편입니다").
- **가운뎃점(·) 쓰지 말 것** — 사람이 안 쓰는 기호라고 봄. 쉼표와 "그리고/과/와"로 자연스럽게 나열.
- 단정적이되 겸손. 자기 자랑 톤 X, "~라고 생각합니다" 정도의 톤.
- 문장은 짧게, 주장마다 구체 사례와 숫자로 뒷받침(예: "300건 전수 검사해 정합률 100%").
- 담백하지만 자신감은 있게("~에 가깝다고 봅니다" 같은 과한 조심 표현 대신 "~합니다").

**Why:** 본인이 직접 최종 문구를 여러 번 다듬으며 날선 표현·기호·과장을 걷어내는 방향으로 일관되게 교정함(2026-07-09 세션).
**How to apply:** 우진님 명의 글 초안을 쓸 때 이 톤을 기본값으로. 초안 후 · 제거, 격언조·대조 완화, 수치 근거 확인. 과제 보고서체는 [[user-profile]], 성찰지는 [[reflection-essay-writing-style]] 참고(장르별로 다름).

**[추가 2026-08-12] 초안 후 점검 목록** (생성 중 금지어가 아님 — 다 쓴 뒤 한 번 훑으며 어색하게 쓰인 것만 수정):
- 항상 규칙(기존과 동일): 가운뎃점·em dash 금지, 장식 이모지 금지, 감사·인사 반복 금지.
- 경고 패턴(무의미하게 쓰였을 때만 고침): "단순히 X가 아니라 Y"류 대조 구문 반복, 억지로 맞춘 3항 나열, 구체 내용 없는 "다양한/효율적인/체계적인/전반적인", "~을 통해/~함으로써/~에 있어서" 번역투 연쇄, 모든 문장이 "~할 수 있습니다"로 끝나는 것, 뻔한 결론 앞의 "결론적으로/궁극적으로", 문단마다 볼드 라벨.
- voice 샘플: **~/App/woojin/voice/** (2026-08-12 확정, 13편 + INDEX.md). 명의 글 작업 시 INDEX.md를 읽고 가장 가까운 장르의 샘플 1~2편만 참고 — 정보 순서와 문장 리듬만 따르고 사실관계·고유명사 복사 금지. 장르별 관찰 특징(수치로 끝맺기, 유보적 판단 등)은 INDEX.md에 있음. 격식 메일은 04 발송 스레드가 기준, ~/App/woojin/memory/woojin-formal-email-tone.md 병행 참고.

**[추가 2026-08-14] 수상·경력·프로필 항목은 관례 포맷으로 건조하게:** 상 이름 + 규모 + 만든 것, 한 줄. 서사·행위 서술("방어했다", "완성해냈다")은 오글거림으로 기각됨 — "실제 수상자들 어떻게 쓰는지 봐봐"가 교정 방향이었음. 자소서·포트폴리오도 같은 감각: 멋있게 쓰려는 문장이 나오면 관례와 사실 진술로 회귀. INDEX.md에도 같은 규칙 있음(코덱스 공유).

**[추가 2026-08-12] 카톡·메시지 문안도 같은 방향:** 짧고 자연스럽고 예의 갖추되 격식 과잉 금지. "마지막에 감사합니다 3번은 머냐"(8/12) — 같은 감사·인사 표현 반복 제거, "좀 더 자연스럽게"가 반복 요청됨. 거절·안부 메시지는 특히 간결하게.
