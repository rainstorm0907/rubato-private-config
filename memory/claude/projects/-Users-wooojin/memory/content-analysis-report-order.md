우진님이 영상이나 글을 분석시키면, 보고 순서는 반드시 ① 그 콘텐츠 자체의 요약 ② 우리 세팅에 적용할 것 제안. 요약을 건너뛰고 바로 적용안·검증 결과부터 던지면 안 됨. 분석 과정에서 일부 내용을 기각했다면 기각했다고 명시할 것 — 말 안 하면 "읽긴 한 거야?"가 됨(2026-08-12 "AI 냄새" 영상 세션에서 교정).

**Why:** 영상의 색 프로필·레퍼런스 지정 부분을 내부적으로만 반영하고 언급하지 않았더니 "기각한 거야? 왜 말 안 해줘?"라는 지적을 받음. 또 내부 작업 용어(경고 패턴, 검수 루프 등)를 그대로 사용자 설명에 씀 — [[explain-plain-register]] 위반 재발.
**How to apply:** 콘텐츠 분석 보고 첫 섹션은 항상 원문 요약. 이후 적용안은 원문 항목별로 채택/변형/기각을 대응시켜 빠뜨린 항목이 없게. 설명은 쉬운 말로.
