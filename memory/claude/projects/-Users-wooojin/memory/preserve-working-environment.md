세 사건에서 나온 같은 계열 교훈:
- "아까 방식대로 했다가 다른 기기 노트북이 계정 로그아웃 되어버렸어. 그거 안그러게 조심하고 절대로."(7/31) — 계정 전환·자격증명 조작이 다른 기기 세션을 죽임.
- "아니 원래 켜졌었는데 뭔소리야 왜 뭘깔아??? 잘되던 위스키 다시 다운로드 안돼?"(8/7) — 전에 작동하던 경로(Whisky/Wine)를 놔두고 새 도구부터 설치하다 제지.
- Cofathon Probe 스크린샷 유실(8/3) — 외부 브라우저 세션이 닫힌 뒤 복원 시도("진짜 마지막 이거 없으면 포기할게")까지 갔음.

**Why:** 우진님 환경은 여러 기기·계정·외부 세션이 얽혀 있어, "고치기"가 "다른 곳 부수기"가 되기 쉬움. 손실은 비가역이고 신뢰 비용이 큼.

**How to apply:** ① 로그인·계정·키체인 관련 조작 전엔 다른 기기 영향 여부를 먼저 따지고 위험하면 물어볼 것 ② "전에 됐다"는 정보가 있으면 기존 경로 복구 우선, 대체 설치는 사유 설명+승인 후 ③ 외부/브라우저 세션의 산출물(스크린샷·원문)은 세션이 살아있을 때 로컬 복사. 관련: [[consult-chatgpt-research]](계정 고정 규칙), [[codexbar-keychain-popup-fix]].
