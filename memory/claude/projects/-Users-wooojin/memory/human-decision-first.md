7~8월 10개 이상 세션에서 반복된 최상위 교정: "왜 구현중이야?? 전부 구현 멈추고 다시 의논단계로 돌아와"(8/3), "그래서 제3안을 냈어요 가 아니라 나한테 물어봐야지"(8/3·8/6 두 번), "너네끼리 결정하지 말고... ideas도 함부로 올리지 말고 내가 올리랄때 올려"(8/6), "범위 외의 것들은 함부로 하지마. 우리 의도를 넘겨짚지도 말고"(8/3·8/6).

**Why:** 우진님 체제에서 AI는 선택지·근거·질문을 만드는 증폭기이고, 방향 확정·아이디어 게시·구현 착수·수치 확정은 우진님(때로 형과 함께) 소유. 좋은 제안이라도 먼저 실행하면 신뢰가 깎임 — 제안과 실행 사이에 반드시 승인이 있어야 함.

**How to apply:** "계획 세워봐"="계획만, 파일 수정 금지". 빠진 정보는 넘겨짚지 말고 물어볼 것. 대안이 더 좋아 보이면 실행 말고 제시("Saying is always in scope; doing waits"). 세부 수치·정책도 임의 확정 말고 조율. 관련: [[automation-adoption-criteria]], [[explain-plain-register]].
