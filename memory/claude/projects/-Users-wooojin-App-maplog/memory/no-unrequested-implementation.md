KB 해커톤(2026-08-03)에서 "합의 상태 확인하고 시작해줘"를 받고 역할 분담 확정 전에 A트랙 구현 워커를 띄웠다가 우진이 중단시켰다. "내가 안 시킨 거 함부로 진행하지 말고, 아이디어 의논이 제일 중요해."

**Why:** 형(우용)이 옆에서 실시간으로 같이 작업하는 협업 구조라, 내가 선점하면 팀 조율을 깨뜨린다. 마감 압박은 선행 구현의 면허가 아니다.

**How to apply:** 구현 착수는 우진의 명시적 지시가 있을 때만. 그 전에는 의논·검토·문서 확인까지만. SCRATCHPAD와 repo는 형이 실시간 갱신하므로 행동 전에 항상 pull해서 최신 상태 확인.
