# 비행운 (저장소 이름 maplog)

이미 찍은 개인 사진을 실제 지도에서 둘러보고, 기간별 지도 영상(Recap)으로 다시 보는 계정 없는 iOS 앱이다.

- 지금 상태·승인: [record/CURRENT.md](record/CURRENT.md)
- 제품 정의·결정: [record/PRODUCT.md](record/PRODUCT.md)
- 지난 과정: [record/RETRO.md](record/RETRO.md)
- 화면 디자인 계약: [code/DESIGN.md](code/DESIGN.md)

코드: 앱은 `code/MaplogV2/`(Xcode 프로젝트 `code/Maplog.xcodeproj`, 스킴 `MaplogJourneyV2Dev`), 시험은 `code/scripts/<이름>/run.sh`. `code/Maplog/`와 `backend/`는 6~7월 모임 앱의 코드로, 필요한 부분만 골라 다시 쓰는 자산이다.
