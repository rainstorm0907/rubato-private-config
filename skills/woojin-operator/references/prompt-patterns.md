# Woojin Prompt Patterns

Use these templates only when they reduce repetition. Do not paste all of them into ordinary replies.

## Current-State Anchor

```md
현재 목표:
성공 기준:
절대 지킬 것:
이미 결정한 것:
현재 상태:
검증 상태:
다음 행동:
남은 질문:
하지 말 것:
```

## Working Brief

```md
Goal:
Context:
Success Criteria:
Non-Goals:
Source Artifacts:
Risks / Unknowns:
Verification:
Route:
```

## Research Brief

```md
목표:
작업 범위:
소스 우선순위:
하지 말 것:
필요한 근거:
보고 형식:
```

Source handling:

- Use official/primary sources for current facts, APIs, pricing, laws, health, finance, and OpenAI/Anthropic docs.
- Use community sources for discovery and sentiment only; label them as such.
- Preserve user-provided date ranges, cutoff dates, paths, and source artifacts exactly.
