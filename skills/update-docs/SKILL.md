# 기존 기록을 현재 작업에 맞춘다

[공통 작성 원칙](../wrapping-sessions/references/documentation.md)을 적용해.
이미 문맥에 있으면 다시 읽지 않고, wrapping-sessions 전체 절차를 새로 실행하지 않아.

지정한 파일이나 현재 과제의 대표 문서를 찾아 이번 변경에 관련된 부분부터 읽어.
현재 상태·결정·결과·남은 질문이 바뀌었다면 해당 절을 갱신하고, 당시 사건을
보존해야 하는 내용만 필요한 이력에 덧붙여. 맨 위의 오래된 결론을 그대로 두지 않아.

참조가 충돌하거나 이전 경험의 조건을 바꾸는 판단이면 관련 원문으로 돌아가 확인해.
전체 회고를 요청받지 않았다면 모든 세션·체크포인트를 다시 읽지 않아.
원문과 작성시각·개정은 실제 확인한 값을 쓰고, 예시 모델명이나 전체 재생 완료를 복사하지 않아.

지정한 문서가 정말 없다면 기존 프로젝트 기록 위치에서 처리해. 새 문서가 필요한지
스스로 판단할 수 있는 범위는 처리하고, 중요한 문서 목적이 달라질 때만 확인해.
수정한 경로와 핵심 변경·남은 확인만 반환해. stage·commit·push는 하지 않아.
